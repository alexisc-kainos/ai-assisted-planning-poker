Jira ticket header — 3 layout concepts

For review: the Jira issue key and ticket title currently render on separate lines in the ticket list, the "Now voting" panel and the ticket overlay. All 3 concepts below apply the same box pattern — key box before a title box, same line when space allows, wrapping (not truncating) on narrow screens — and only differ in how strongly the key box stands out. Each context is shown at a normal width and a narrow (~220px) width to preview the wrap behaviour.

Concept A — Outline tag

Thin teal outline, no fill. Lowest visual weight — the title box stays the main focus.
